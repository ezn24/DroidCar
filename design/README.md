# Design prototypes

HTML prototypes the car launcher and the phone UI were first drawn in (open them in a browser):

- `launcher-proto.html`: the car launcher at the 1160x540 @ 420 dpi design base. The dock, desktop grid and clock sizes
  in the code are derived from it (see "Dock and launcher grid" in AGENTS.md).
- `phone-ui-proto.html`: the phone UI (connection hero card, readiness list, settings).

They are references only; the app's look has moved on since (glass dock, dashboard, setup guide). The phone preview in
the README is drawn separately (`docs/screenshots/phone-home.png`).
